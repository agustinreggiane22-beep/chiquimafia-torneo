Activar goles oficiales y votación de MVP

La web está preparada para usar este código. Para habilitar las barras de votos en vivo, actualizá el código de la aplicación de Google Apps Script que ya está conectada al torneo.

  1. En tu planilla, abrí Extensiones → Apps Script.
  2. Copiá todo el código de abajo y reemplazá el contenido de Código.gs. Guardá. Se conservan el PIN y los registros existentes.
  3. Arriba, elegí la función setupTournamentAutomation, tocá Ejecutar y aceptá los permisos que Google solicita para crear los temporizadores. Este paso se hace una sola vez. Si ya activaste el cierre automático, omití este paso.
  4. Entrá en Implementar → Administrar implementaciones → Editar. Elegí Nueva versión → Implementar sobre la implementación web existente. Así se conserva la URL que usa la página. Debe ejecutarse como vos y permitir acceso a cualquiera.
  5. Recargá la página del torneo. El apartado cambia automáticamente a Votación de MVP.

Las anotaciones locales del marcador solo llegan a las estadísticas cuando publicás el resultado. Los partidos anteriores conservan sus registros. No hace falta reiniciar la temporada ni borrar hojas.
